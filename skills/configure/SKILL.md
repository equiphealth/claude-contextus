# configure

**Edit config** — interactive config editor for `.claude/contextus.jsonc`.

## When to use

- User wants to change retrieval settings
- Editing source paths, excludes, or thresholds
- User asks to "configure contextus" or "edit config"

## Instructions

Conversational. Show current config, ask what to change, validate, write.
