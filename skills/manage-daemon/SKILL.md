# manage-daemon

**Daemon control** — start, stop, restart the contextus daemon.

## When to use

- After config changes that require restart
- Daemon is unresponsive or crashed
- User asks to "restart daemon" or "stop contextus"

## Instructions

Execute silently. Run daemon control command, verify status.

See [./reference.md](./reference.md) for:
- When restart is required
- Health check commands
- Troubleshooting
