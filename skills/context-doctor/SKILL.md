# context-doctor

**Diagnostics and troubleshooting** — find and fix contextus issues.

## When to use

- User reports retrieval issues, missing patterns, or injection failures
- Daemon won't start or keeps crashing
- Patterns not appearing despite high similarity
- After major config or DB changes

## Instructions

Execute silently. Run diagnostics, present findings, suggest fixes.

- Common issues and fixes
